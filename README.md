# WebLab — Модуль 1: Живой тренажёр по HTTP, Cookies, Статус-кодам, JWT и DevTools (F12)

Интерактивный учебный веб-стенд на чистом Python (только стандартная библиотека, без внешних зависимостей) для практической отработки Модуля 1.

## Что внутри
1. **HTTP-методы (`GET`, `POST`, `PUT`, `DELETE`):** поиск с URL-параметрами и кастомным заголовком `X-Student-Tag`, создание/изменение/удаление заметок.
2. **Полигон настоящих статус-кодов:** `200`, `201`, `302` (в том числе редирект страницы для проверки **`Keep log`**), `304 Not Modified` (по `ETag`), `400`, `401`, `403`, `404`, `429 Too Many Requests` (реальный Rate Limit) и `500`.
3. **Cookies, Сессии и JWT:** сравнение обычной cookie (`public_user`) и защищённой `HttpOnly` cookie (`lab_session`), проверка ролей (`student` vs `mentor`), разборщик **JWT** с проверкой HMAC-SHA256 подписи на сервере.
4. **Клиент vs Сервер:** симулятор интернет-магазина с переключением «Наивный сервер» / «Защищённый сервер».
5. **6 практических квестов для DevTools (`F12`):** `Elements`, `Response Headers`, `Keep log + 302`, `Application → Cookies`, роли `403 → 200` и отлов `429`.

## Как запустить локально (Windows)
1. Дважды кликни по файлу **`Запустить_Тренажер.bat`** (или выполни `python server.py` в папке проекта).
2. Откроется адрес `http://127.0.0.1:8080`.
3. Нажми **`F12`** → вкладка **`Network`** → включи **`Keep log`** и следуй инструкции в **[Шпаргалка_Модуль1.md](Шпаргалка_Модуль1.md)**.

---

## Как запустить прямо из GitHub (GitHub Codespaces)
1. Открой этот репозиторий на GitHub.
2. Нажми зелёную кнопку **`<> Code`** → вкладка **`Codespaces`** → **`Create codespace on main`**.
3. В терминале внизу выполни:
   ```bash
   python3 server.py --no-browser
   ```
4. Нажми **`Open in Browser`** во всплывающем уведомлении (или перейди во вкладку **`PORTS`**, порт `8080`, и нажми на иконку глобуса).

---

## Как выложить на постоянный бесплатный хостинг (Render.com)
1. Зайди на [render.com](https://render.com) через GitHub → **New +** → **Web Service**.
2. Подключи этот репозиторий.
3. Укажи параметры:
   * **Runtime:** `Python 3`
   * **Build Command:** *(оставь пустым или укажи `echo ready`)*
   * **Start Command:** `python server.py --no-browser`
   * **Instance Type:** `Free`
4. Нажми **Create Web Service** — через 1–2 минуты сайт заработает по постоянной HTTPS-ссылке (сервер сам подхватит порт из переменной окружения `PORT`).
