1A. Метод GET — чтение и поиск через URL-параметры

GET

Параметры поиска передаются прямо в адресе (?q=...&category=...), а не в теле запроса. Попробуй также передать свой заголовок X-Student-Tag и найди его в Network → Headers → Request Headers.

1B. Методы POST, PUT и DELETE — управление заметками на сервере

POST 201 PUT 200 DELETE 200

При создании заметки данные улетают в теле запроса (Body / Payload) в формате JSON, а сервер возвращает статус 201 Created.

2xx / 3xx / 4xx / 5xx

Нажимай на кнопки и наблюдай, как меняется цветная строчка статуса в колонке Status в DevTools → Network и в «Зеркале ответа» справа.

5. Практические квесты для DevTools (F12)

Практика

Пройди все 6 мини-заданий руками через F12. Как только найдёшь ответ или флаг (формата FLAG-...) — впиши его в поле и нажми «Проверить».

Квест 1. Инспектор страницы (вкладка Elements)

Не пройден

Открой вкладку Elements в DevTools (или нажми правой кнопкой мыши по цветному блоку ниже → «Просмотреть код»). Найди скрытый HTML-атрибут data-secret-flag и попробуй прямо в DevTools изменить видимый текст внутри блока.

Нажми на меня правой кнопкой → «Просмотреть код» (Elements), чтобы найти скрытый атрибут!

Квест 2. Секрет в заголовках ответа (Network → Headers)

Не пройден

Нажми кнопку ниже: сервер вернёт JSON, но сам флаг спрячет не в тексте ответа, а в HTTP-заголовке X-DevTools-Flag внутри раздела Response Headers.

Квест 3. Поймать редирект с Keep log (Network)

Не пройден

Открой F12 → Network и поставь галочку Keep log (Preserve log). Нажми кнопку ниже — страница перезагрузится через настоящий статус 302. Без Keep log первый запрос пропал бы, а с ним ты увидишь строчку 302-page!

Квест 4. Защищённая Cookie (Application → Cookies vs Console)

Не пройден

Войди во вкладке 3. Cookies, Сессии и JWT как student. Нажми «Прочитать document.cookie», а затем открой F12 → Application → Cookies. Впиши имя той cookie, у которой стоит галочка HttpOnly и которой нет в document.cookie.

Квест 5. Проверка ролей на сервере (403 → 200)

Не пройден

Во вкладке 3 попробуй зайти в /admin-panel под student — увидишь 403 Forbidden. Затем войди под наставником (mentor / admin123), снова открой панель и найди флаг в JSON-ответе.

Квест 6. Поймать защиту от перебора (429 Too Many Requests)

Не пройден

Нажми кнопку ниже быстро 4 раза за 10 секунд (или сделай это во вкладке «2. Статус-коды»): первые 3 раза сервер ответит 200, а на 4-й вернёт настоящий 429 с заголовком Retry-After.
